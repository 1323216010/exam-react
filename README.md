# exam-react

独立的 Vite + React + TypeScript 自考刷题试验版，原站不受影响。

## 已实现
- 科目筛选、试卷搜索、221 套原题库 JSON
- 单选、多选、主观题输入与答题卡
- 自动保存本地进度、继续作答、重新开始
- 客观题判分、主观题参考答案（不伪造总成绩）
- 响应式手机布局；空卷禁用
- 一月三科考点学习：法学概论 22、电子政务 37、公共政策 8 个单元
- 回忆要点、自查进度、关联选择题和 67 个来源试卷入口

## 开发
```sh
npm ci
npm run dev
npm run build
npx vitest run
npm run lint
```

题库快照来自 https://github.com/1323216010/exam 。未导入商业 App 旧大纲考点题。00318 仅作为旧课码练习资料，不称为 13672 历年真题。

这是核心流程首版，不是原站完整迁移。AI 对话、AI 主观题评分、计时模拟及错题专项尚未移植。考点学习已迁移内容和核心自查流程，原站的定时复习调度尚未迁移。进度与原站不共用，清除浏览器数据会丢失进度。

Vercel 采用 Vite 预设，构建 `npm run build`，输出 `dist`。保持原站域名不变，先用独立项目预览。
